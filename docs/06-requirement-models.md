# 06 — Requirement Models: User Stories, Use Cases and Acceptance Criteria

> **Week 6 deliverable**

## 1. User Stories

| **ID** | **User Story** | **Priority** | **Linked FR** | **Acceptance Criteria** |
|---|---|---|---|---|
| US-01 | As a ผู้ดูแลอุปกรณ์, I want to บันทึกและค้นหาประวัติการยืม–คืนของอุปกรณ์แต่ละชิ้นแบบดิจิทัล, so that เพื่อให้ตรวจสอบข้อมูลการใช้งานย้อนหลังได้รวดเร็วและสะดวก | Must | FR-EQP-01 | AC-01, AC-02 |
| US-02 | As a ผู้ดูแลอุปกรณ์, I want to บันทึกสภาพอุปกรณ์พร้อมภาพถ่ายและหลักฐานประกอบทั้งตอนส่งมอบและตอนรับคืน, so that เพื่อให้มีหลักฐานที่ชัดเจนในการตรวจสอบความเสียหายและลดข้อพิพาท | Must | FR-EQP-02 | AC-03, AC-04 |
| US-03 | As a ผู้ยืม, I want to ดูข้อมูลและหลักฐานสภาพอุปกรณ์ก่อนยืมและหลังคืนของรายการที่ตนเองเกี่ยวข้อง, so that เพื่อให้สามารถตรวจสอบและยืนยันสภาพอุปกรณ์ได้อย่างเป็นธรรมเมื่อเกิดข้อโต้แย้ง | Must | FR-EQP-02 | AC-05, AC-06 |
| US-04 | As a ผู้ยืม, I want to ส่งคำขอยืมอุปกรณ์ประเภทพิเศษหรือราคาสูงพร้อมข้อมูลกิจกรรมและกำหนดคืน, so that เพื่อให้คำขอได้รับการพิจารณาและอนุมัติตามเงื่อนไขของอุปกรณ์ | Should | FR-EQP-03 | AC-07, AC-08 |
| US-05 | As a ผู้ดูแลอุปกรณ์, I want to เรียกคืนอุปกรณ์ก่อนกำหนดพร้อมบันทึกเหตุผลและแจ้งให้ผู้ยืมทราบล่วงหน้า, so that เพื่อให้อุปกรณ์สามารถถูกนำกลับมาจัดสรรให้กิจกรรมที่มีความจำเป็นเร่งด่วนกว่า | Should | FR-EQP-04 | AC-09, AC-10 |
| US-06 | As a ชมรม/ผู้จัดกิจกรรม, I want to ตรวจสอบสถานะความพร้อมและช่วงเวลาที่อุปกรณ์ว่างก่อนทำการจอง, so that เพื่อให้สามารถวางแผนเลือกอุปกรณ์ที่พร้อมใช้งานได้โดยไม่ต้องคาดเดา | Must | FR-EQP-05 | AC-11, AC-12 |
| US-07 | As a ชมรม/ผู้จัดกิจกรรม, I want to จองอุปกรณ์ล่วงหน้าตามช่วงเวลาที่ต้องการ โดยระบบป้องกันการจองที่เวลาทับซ้อนกัน, so that เพื่อให้มั่นใจว่าการจองที่ยืนยันแล้วจะไม่ถูกจองซ้ำโดยผู้อื่น | Must | FR-EQP-05 | AC-13, AC-14 |
| US-08 | As a เจ้าหน้าที่/ผู้บริหาร, I want to ดูข้อมูลสรุปจำนวนครั้งที่อุปกรณ์ถูกยืม ประวัติความชำรุด สถานะปัจจุบัน ผู้ถือครอง และกำหนดคืน, so that เพื่อใช้ติดตามการใช้งานและวางแผนซ่อมบำรุงหรือจัดซื้ออุปกรณ์ | Could | FR-EQP-06 | AC-15, AC-16 |
