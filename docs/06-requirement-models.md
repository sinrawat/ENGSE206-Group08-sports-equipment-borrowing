## 2. Acceptance Criteria

### AC-01 — ค้นหาประวัติการยืม–คืน

- Given ระบบมีข้อมูลประวัติการยืม–คืนของอุปกรณ์
- When ผู้ดูแลอุปกรณ์ค้นหาประวัติของอุปกรณ์ที่ต้องการ
- Then ระบบแสดงรายการประวัติการยืม–คืนของอุปกรณ์นั้น

### AC-02 — แสดงรายละเอียดประวัติการยืม–คืน

- Given ระบบแสดงรายการประวัติการยืม–คืนของอุปกรณ์
- When ผู้ดูแลอุปกรณ์เลือกรายการประวัติหนึ่งรายการ
- Then ระบบแสดงข้อมูลผู้ยืม สถานะ และรายละเอียดการยืม–คืนของรายการนั้น


### AC-03 — บันทึกสภาพอุปกรณ์ก่อนส่งมอบ

- Given มีรายการยืมที่พร้อมส่งมอบอุปกรณ์
- When ผู้ดูแลอุปกรณ์บันทึกสภาพและภาพถ่ายของอุปกรณ์ก่อนส่งมอบ
- Then ระบบบันทึกข้อมูลสภาพและภาพถ่ายไว้กับรายการยืมนั้น

### AC-04 — บันทึกสภาพอุปกรณ์หลังรับคืน

- Given มีรายการยืมที่ผู้ยืมนำอุปกรณ์กลับมาคืน
- When ผู้ดูแลอุปกรณ์บันทึกสภาพและภาพถ่ายของอุปกรณ์หลังรับคืน
- Then ระบบบันทึกข้อมูลสภาพและภาพถ่ายหลังรับคืนไว้กับรายการยืมนั้น


### AC-05 — ดูหลักฐานสภาพก่อนยืม

- Given ผู้ยืมมีรายการยืมอุปกรณ์ที่เกี่ยวข้องกับตนเองและมีหลักฐานก่อนส่งมอบ
- When ผู้ยืมเปิดดูรายการยืมของตนเอง
- Then ระบบแสดงข้อมูลและหลักฐานสภาพอุปกรณ์ก่อนยืม

### AC-06 — ดูหลักฐานสภาพหลังคืน

- Given ผู้ยืมมีรายการยืมที่ดำเนินการคืนแล้วและมีหลักฐานหลังรับคืน
- When ผู้ยืมเปิดดูรายการยืมของตนเอง
- Then ระบบแสดงข้อมูลและหลักฐานสภาพอุปกรณ์หลังคืน


### AC-07 — ส่งคำขอยืมอุปกรณ์ประเภทพิเศษ

- Given ผู้ยืมมีสิทธิ์ขอยืมอุปกรณ์ประเภทพิเศษหรือราคาสูง และมีข้อมูลกิจกรรมกับกำหนดคืน
- When ผู้ยืมส่งคำขอยืมอุปกรณ์
- Then ระบบบันทึกคำขอและแสดงสถานะว่าคำขออยู่ระหว่างการพิจารณา

### AC-08 — ตรวจสอบผลการพิจารณาคำขอ

- Given มีคำขอยืมอุปกรณ์ประเภทพิเศษหรือราคาสูงที่อยู่ระหว่างการพิจารณา
- When ผู้มีอำนาจบันทึกผลการพิจารณาคำขอ
- Then ระบบแสดงสถานะคำขอเป็นผลการพิจารณาที่บันทึกไว้


### AC-09 — เรียกคืนอุปกรณ์ก่อนกำหนด

- Given มีอุปกรณ์ที่อยู่ระหว่างการยืมและมีเหตุผลในการเรียกคืน
- When ผู้ดูแลอุปกรณ์ดำเนินการเรียกคืนอุปกรณ์
- Then ระบบบันทึกสถานะการเรียกคืนและเหตุผลที่ระบุ

### AC-10 — แจ้งผู้ยืมเกี่ยวกับการเรียกคืน

- Given ผู้ดูแลอุปกรณ์บันทึกการเรียกคืนอุปกรณ์ก่อนกำหนดแล้ว
- When ระบบดำเนินการแจ้งผู้ยืม
- Then ผู้ยืมสามารถเห็นข้อมูลการเรียกคืนและเหตุผลที่ระบุไว้


### AC-11 — ตรวจสอบสถานะอุปกรณ์ตามช่วงเวลา

- Given ระบบมีข้อมูลสถานะและช่วงเวลาการใช้งานของอุปกรณ์
- When ชมรมหรือผู้จัดกิจกรรมระบุช่วงเวลาที่ต้องการใช้อุปกรณ์
- Then ระบบแสดงสถานะความพร้อมของอุปกรณ์ในช่วงเวลานั้น

### AC-12 — แสดงอุปกรณ์ที่สามารถจองได้

- Given ระบบแสดงสถานะอุปกรณ์ตามช่วงเวลาที่ผู้จัดกิจกรรมเลือก
- When ชมรมหรือผู้จัดกิจกรรมเลือกดูเฉพาะอุปกรณ์ที่ว่าง
- Then ระบบแสดงเฉพาะรายการอุปกรณ์ที่สามารถจองได้


### AC-13 — จองอุปกรณ์ล่วงหน้า

- Given อุปกรณ์ที่ต้องการจองว่างในช่วงเวลาที่กำหนด
- When ชมรมหรือผู้จัดกิจกรรมส่งคำขอจองอุปกรณ์
- Then ระบบบันทึกรายการจองพร้อมอุปกรณ์และช่วงเวลาที่ระบุ

### AC-14 — ป้องกันการจองช่วงเวลาทับซ้อน

- Given อุปกรณ์ชิ้นเดียวกันมีการจองที่ยืนยันแล้วในช่วงเวลาหนึ่ง
- When ชมรมหรือผู้จัดกิจกรรมพยายามจองอุปกรณ์ชิ้นเดียวกันในช่วงเวลาที่ทับซ้อน
- Then ระบบไม่สร้างรายการจองใหม่และแสดงว่าอุปกรณ์ไม่ว่างในช่วงเวลานั้น


### AC-15 — แสดงข้อมูลสรุปการใช้งานอุปกรณ์

- Given ระบบมีข้อมูลการยืม–คืนและข้อมูลสภาพอุปกรณ์
- When เจ้าหน้าที่หรือผู้บริหารเปิดข้อมูลสรุปการใช้งาน
- Then ระบบแสดงจำนวนครั้งที่ยืม ประวัติความชำรุด และสถานะปัจจุบันของอุปกรณ์

### AC-16 — แสดงข้อมูลสำหรับติดตามและวางแผน

- Given ระบบมีข้อมูลสรุปการใช้งานและสภาพของอุปกรณ์
- When เจ้าหน้าที่หรือผู้บริหารเลือกดูข้อมูลของอุปกรณ์
- Then ระบบแสดงข้อมูลที่ใช้สำหรับติดตามการใช้งานและวางแผนซ่อมบำรุงหรือจัดซื้อ

## 4. Use Case Specification

### UC-01 — จัดการประวัติการยืม–คืนอุปกรณ์

| **Field** | **Detail** |
|---|---|
| Primary Actor | ผู้ดูแลอุปกรณ์ |
| Trigger | ผู้ดูแลอุปกรณ์ต้องการบันทึกหรือค้นหาประวัติการยืม–คืน |
| Preconditions | ระบบมีข้อมูลอุปกรณ์และรายการยืม–คืน |
| Main Success Scenario | 1. ผู้ดูแลเลือกอุปกรณ์ 2. ระบบแสดงข้อมูลประวัติ 3. ผู้ดูแลค้นหาหรือเลือกช่วงข้อมูลที่ต้องการ 4. ระบบค้นหาข้อมูล 5. ระบบแสดงรายการประวัติที่ตรงกับข้อมูลที่ค้นหา |
| Alternate / Exception Flows | หากไม่พบประวัติที่ตรงกับข้อมูลที่ค้นหา ระบบแสดงว่าไม่พบข้อมูล |
| Postconditions | ข้อมูลประวัติการยืม–คืนสามารถตรวจสอบย้อนหลังได้ |
| Related Requirements | FR-EQP-01 |

### UC-02 — บันทึกสภาพอุปกรณ์ก่อนและหลังการยืม

| **Field** | **Detail** |
|---|---|
| Primary Actor | ผู้ดูแลอุปกรณ์ |
| Trigger | มีการส่งมอบหรือรับคืนอุปกรณ์ |
| Preconditions | มีรายการยืมที่เกี่ยวข้องกับอุปกรณ์ |
| Main Success Scenario | 1. ผู้ดูแลเลือกอุปกรณ์ 2. ตรวจสอบสภาพอุปกรณ์ 3. บันทึกสภาพก่อนส่งมอบหรือหลังรับคืน 4. เพิ่มภาพถ่ายหรือหลักฐานประกอบ 5. ระบบบันทึกข้อมูลสภาพไว้กับรายการยืม |
| Alternate / Exception Flows | หากข้อมูลสภาพหรือหลักฐานไม่ครบ ระบบแจ้งให้ผู้ดูแลดำเนินการให้ครบก่อนบันทึก |
| Postconditions | ระบบมีข้อมูลสภาพและหลักฐานของอุปกรณ์สำหรับช่วงเวลาที่บันทึก |
| Related Requirements | FR-EQP-02 |

### UC-03 — ตรวจสอบหลักฐานสภาพอุปกรณ์

| **Field** | **Detail** |
|---|---|
| Primary Actor | ผู้ยืม |
| Trigger | ผู้ยืมต้องการตรวจสอบสภาพอุปกรณ์ของรายการที่ตนเองเกี่ยวข้อง |
| Preconditions | ผู้ยืมมีรายการยืมในระบบและมีข้อมูลหลักฐานที่เกี่ยวข้อง |
| Main Success Scenario | 1. ผู้ยืมเปิดรายการยืม 2. ระบบตรวจสอบสิทธิ์ของผู้ยืม 3. ระบบแสดงข้อมูลสภาพก่อนยืม 4. ระบบแสดงหลักฐานที่เกี่ยวข้อง 5. ผู้ยืมตรวจสอบข้อมูล |
| Alternate / Exception Flows | หากไม่มีหลักฐานสำหรับรายการนั้น ระบบแสดงว่าไม่มีข้อมูลหลักฐาน |
| Postconditions | ผู้ยืมสามารถตรวจสอบข้อมูลและหลักฐานสภาพอุปกรณ์ได้ |
| Related Requirements | FR-EQP-02 |

### UC-04 — ส่งคำขอยืมอุปกรณ์ประเภทพิเศษ

| **Field** | **Detail** |
|---|---|
| Primary Actor | ผู้ยืม |
| Trigger | ผู้ยืมต้องการยืมอุปกรณ์ประเภทพิเศษหรือราคาสูง |
| Preconditions | ผู้ยืมสามารถส่งคำขอยืมอุปกรณ์ได้และมีข้อมูลที่จำเป็นสำหรับคำขอ |
| Main Success Scenario | 1. ผู้ยืมเลือกอุปกรณ์ 2. กรอกข้อมูลกิจกรรม 3. ระบุกำหนดคืน 4. ส่งคำขอ 5. ระบบตรวจสอบข้อมูล 6. ระบบบันทึกคำขอ 7. ระบบส่งคำขอเข้าสู่กระบวนการพิจารณา |
| Alternate / Exception Flows | หากข้อมูลคำขอไม่ครบ ระบบไม่บันทึกคำขอและแจ้งข้อมูลที่ต้องแก้ไข |
| Postconditions | มีคำขอยืมอุปกรณ์ประเภทพิเศษหรือราคาสูงในระบบเพื่อรอการพิจารณา |
| Related Requirements | FR-EQP-03 |

### UC-05 — เรียกคืนอุปกรณ์ก่อนกำหนด

| **Field** | **Detail** |
|---|---|
| Primary Actor | ผู้ดูแลอุปกรณ์ |
| Trigger | ผู้ดูแลอุปกรณ์มีความจำเป็นต้องเรียกคืนอุปกรณ์ก่อนกำหนด |
| Preconditions | อุปกรณ์อยู่ระหว่างการยืม |
| Main Success Scenario | 1. ผู้ดูแลเลือกอุปกรณ์ที่ต้องการเรียกคืน 2. ระบุเหตุผล 3. ระบบตรวจสอบรายการยืม 4. ระบบบันทึกการเรียกคืน 5. ระบบปรับสถานะรายการ 6. ระบบแจ้งข้อมูลการเรียกคืนแก่ผู้ยืม |
| Alternate / Exception Flows | หากไม่พบรายการยืมหรือรายการไม่อยู่ในสถานะที่เรียกคืนได้ ระบบไม่ดำเนินการและแสดงข้อความแจ้งเตือน |
| Postconditions | การเรียกคืนและเหตุผลถูกบันทึก และผู้ยืมได้รับข้อมูลเกี่ยวกับการเรียกคืน |
| Related Requirements | FR-EQP-04 |

### UC-06 — ตรวจสอบสถานะและความพร้อมของอุปกรณ์

| Preconditions | ระบบมีข้อมูลอุปกรณ์และช่วงเวลาการใช้งานหรือการจอง |
| Main Success Scenario | 1. ผู้จัดกิจกรรมระบุช่วงเวลาที่ต้องการ 2. ระบบตรวจสอบข้อมูลการใช้งาน 3. ระบบตรวจสอบการจองที่เกี่ยวข้อง 4. ระบบคำนวณความพร้อมของอุปกรณ์ 5. ระบบแสดงรายการอุปกรณ์ที่พร้อมใช้งาน |
| Alternate / Exception Flows | หากไม่มีอุปกรณ์ที่พร้อมใช้งานในช่วงเวลาที่ระบุ ระบบแจ้งว่าไม่พบอุปกรณ์ที่ว่าง |
| Postconditions | ผู้จัดกิจกรรมทราบรายการอุปกรณ์ที่พร้อมใช้งานในช่วงเวลาที่ต้องการ |
| Related Requirements | FR-EQP-05 |

### UC-07 — จองอุปกรณ์ล่วงหน้า

| Trigger | ผู้จัดกิจกรรมต้องการจองอุปกรณ์สำหรับช่วงเวลาที่กำหนด |
| Preconditions | อุปกรณ์มีสถานะพร้อมจองในช่วงเวลาที่ต้องการ |
| Main Success Scenario | 1. ผู้จัดกิจกรรมเลือกอุปกรณ์ 2. ระบุช่วงเวลาที่ต้องการ 3. ระบบตรวจสอบการจองเดิม 4. ระบบตรวจสอบว่าช่วงเวลาไม่ทับซ้อน 5. ผู้จัดกิจกรรมยืนยันการจอง 6. ระบบบันทึกการจอง 7. ระบบแสดงผลการจองที่สำเร็จ |
| Alternate / Exception Flows | หากช่วงเวลาทับซ้อนกับการจองเดิม ระบบไม่อนุญาตให้จองและแจ้งว่าอุปกรณ์ไม่ว่างในช่วงเวลาดังกล่าว |
| Postconditions | รายการจองถูกบันทึก และไม่เกิดการจองอุปกรณ์ชิ้นเดียวกันในช่วงเวลาที่ทับซ้อน |
| Related Requirements | FR-EQP-05 |
