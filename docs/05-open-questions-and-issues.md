## 3. Follow-up Plan

| Action | Output ที่ต้องได้ | ใช้ต่อใน Week06 อย่างไร |
|---|---|---|
| สัมภาษณ์หัวหน้าศูนย์กีฬา/อาจารย์ผู้รับผิดชอบ เรื่องเกณฑ์อุปกรณ์พิเศษ | เกณฑ์ราคา/รายการ + authority matrix | ใช้ทำ extension flow ของ FR-EQP-03 |
| สัมภาษณ์ผู้ดูแลอุปกรณ์เพิ่มเรื่องกระบวนการถ่ายภาพ/เก็บหลักฐาน | ขั้นตอนที่ใช้งานได้จริง + ผู้รับผิดชอบ | ใช้ทำ Acceptance Criteria ของ FR-EQP-02 |
| สัมภาษณ์ชมรมเพิ่มอย่างน้อย 1 กลุ่ม เรื่องระยะเวลาจองล่วงหน้า | ยืนยัน/ปรับช่วงวันจองล่วงหน้ามาตรฐาน | ใช้กำหนด business rule ของ FR-EQP-05 |
| สัมภาษณ์ผู้ดูแลอุปกรณ์/ผู้ยืมเรื่องการคืนล่าช้า (คำถามใหม่ ไม่ใช่ Q-04 เดิม) | pain point และวิธีจัดการปัจจุบันเมื่อคืนล่าช้า | ใช้ออกแบบสถานะ "ค้างคืน" และ workflow แจ้งเตือนใน Week06 |
| ขอคำยืนยันจากผู้สอน/scope owner เรื่องขอบเขต reporting | คำตัดสินว่า RC-06 ส่วนจัดซื้อ/งบประมาณอยู่ในหรือนอกขอบเขต | กำหนดว่า ISSUE-EQP-01 จะกลายเป็น requirement หรือถูกตัดออกถาวร |
