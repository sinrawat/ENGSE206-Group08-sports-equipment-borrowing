## 1. วัตถุประสงค์การเก็บความต้องการ

- **EO-01:** ยืนยันว่าใครมีอำนาจอนุมัติการยืมอุปกรณ์ประเภทพิเศษ และเงื่อนไข/ขั้นตอนการอนุมัติเป็นอย่างไร
- **EO-02:** ทำความเข้าใจรูปแบบหลักฐานสภาพอุปกรณ์ก่อน–หลังยืมที่ใช้งานได้จริงในบริบทนี้ (ภาพถ่าย/แบบฟอร์ม/อื่นๆ) และใครควรเข้าถึงหลักฐานนี้ได้
- **EO-03:** เก็บ pain points และ workflow ปัจจุบันของการยืม–คืนจากมุมมองผู้ดูแลอุปกรณ์และผู้ยืมจริง เพื่อตรวจสอบว่า Problem Statement ตรงกับประสบการณ์จริงหรือไม่
- **EO-04:** ยืนยัน assumption เรื่องระยะเวลายืม (1–3 วัน) และจำนวนวันที่เปิดให้จองล่วงหน้า (3–7 วัน) ว่าตรงกับการปฏิบัติจริงหรือไม่
- **EO-05:** สำรวจว่ามี stakeholder กลุ่มอื่นที่มีอำนาจตัดสินใจเกี่ยวกับอุปกรณ์เพิ่มเติมหรือไม่ (ตาม open question จาก Week 2)

## 3. Interview / Workshop Guide

### Opening Script

สวัสดีครับ/ค่ะ ทีมงาน ENGSE206 (Case 08) กำลังศึกษาปัญหาการยืม–คืนอุปกรณ์กีฬาและกิจกรรม เพื่อออกแบบระบบที่ช่วยแก้ปัญหานี้ ขอเวลาประมาณ 15–20 นาทีเพื่อสอบถามประสบการณ์และมุมมองของท่าน คำตอบจะถูกใช้เพื่อการเรียนการสอนเท่านั้น จะไม่มีการระบุชื่อจริงในเอกสารที่ส่ง และหากมีการถ่ายภาพจะหลีกเลี่ยงใบหน้าและข้อมูลส่วนบุคคล ท่านสามารถปฏิเสธที่จะตอบคำถามใดก็ได้หากไม่สะดวกใจ

## 4. Consent / Privacy Plan

- ไม่ใช้ชื่อจริงหรือข้อมูลที่ระบุตัวบุคคลได้ในเอกสารส่งงาน ใช้รหัส/นามแฝง เช่น "ผู้ดูแลอุปกรณ์ A"
- หากถ่ายภาพประกอบ (เช่น ขั้นตอนการทำงาน สมุดบันทึก) ให้หลีกเลี่ยงใบหน้าและข้อมูลส่วนบุคคลของผู้ให้สัมภาษณ์
- แจ้งวัตถุประสงค์การใช้ข้อมูลก่อนเริ่มสัมภาษณ์ทุกครั้งตาม Opening Script
- ใช้ข้อมูลจำลอง (mock data) แทนข้อมูลจริงเมื่อสาธิตหรือทดสอบระบบ
- เก็บบันทึก/หลักฐานการสัมภาษณ์ไว้ใน `evidence/` ตามที่กำหนด และลบข้อมูลที่ระบุตัวบุคคลออกก่อน commit

## 5. Elicitation Risks

| Risk | Mitigation |
|---|---|
| ผู้ดูแลอุปกรณ์ไม่สะดวกให้เวลาสัมภาษณ์ในช่วงเปิดเทอม | ใช้ role-play ตามที่อาจารย์กำหนด หรือสัมภาษณ์แบบสั้น 10 นาทีแทน |
| ชมรม/ผู้จัดกิจกรรมมีหลายกลุ่มกระจายตัว คำตอบอาจไม่ตรงกัน | สัมภาษณ์อย่างน้อย 2 ชมรมที่มีลักษณะกิจกรรมต่างกัน แล้วเปรียบเทียบ |
| คำตอบที่ได้อาจเป็นความเห็นส่วนตัว ไม่ใช่นโยบายที่เป็นทางการ | ตรวจสอบคำตอบเรื่องอำนาจอนุมัติ (Q-03) กับเจ้าหน้าที่/ผู้บริหารอีกครั้งเพื่อยืนยัน |
| ผู้ให้สัมภาษณ์ไม่กล้าพูดถึงข้อพิพาทหรือปัญหาที่กระทบความสัมพันธ์ระหว่างฝ่าย | เน้นย้ำเรื่องการไม่ระบุชื่อ และใช้คำถามปลายเปิดแทนคำถามที่ชี้นำว่าใครผิด |
